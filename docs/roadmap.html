🔄 شلون تحدّث جهازك

بعد هالتحديث انضافت مكتبات وجداول جديدة، فلازم:

cd ~/chat
git pull
source .venv/bin/activate
cd backend
pip install -r requirements.txt
python manage.py migrate
daphne -p 8000 config.asgi:application

وبـ Terminal ثاني:

cd ~/chat/frontend
npm install
npm run dev
🔔 تجربة الإشعارات على الكمبيوتر: ادخل بحساب، واضغط "تفعيل" ببطاقة الإشعارات، ووافق على الإذن. بعدين سد التبويب، ومن حساب ثاني (Incognito) دز رسالة. الإشعار يطلع حتى والتبويب مسدود. ملاحظة: نافذة Incognito نفسها ما تدعم الإشعارات.

🧭 المراحل

خلصت المرحلة 1: الأساس المهم

الملف الشخصي، البحث، لوحة المعلومات، إعادة الاتصال، تحسينات الموبايل، PWA، إشعارات Push.

الجاية المرحلة 2: الرسائل

  • إرسال صور وملفات (زر ➕)
  • حذف رسالة ("انحذفت هذه الرسالة") وتعديلها
  • الرد على رسالة معينة
  • حالة "وصلت" ✓✓ رمادي، غير "انقرت" ✓✓ أزرق
  • تحميل الرسائل القديمة على دفعات (مو كلها مرة وحدة)
  • الوضع الليلي

بعدها المرحلة 3: الحسابات والمجموعات

  • تأكيد الحساب بالإيميل (كود 6 أرقام)
  • نسيت كلمة المرور
  • المجموعات: اسم، صورة، أعضاء، مشرف
  • حظر مستخدم

بعدها المرحلة 4: الإطلاق

  • قاعدة بيانات PostgreSQL بدل SQLite
  • Redis حتى نكدر نشغل أكثر من سيرفر
  • رفع على سيرفر بدومين و HTTPS. هنا الإشعارات وتطبيق الشاشة الرئيسية يشتغلن على الموبايل الحقيقي
  • حماية من كثرة الطلبات (rate limiting)، ونسخ احتياطي
